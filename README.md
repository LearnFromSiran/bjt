# bjt
Business level Japanese language study

## BJT Prep (iOS)
Native SwiftUI app (iOS 16+) in `BJTPrep/`: keigo/business-vocab quizzes, spaced-repetition flashcards, streak & progress tracking. Fully offline, no data collected.

Build: `cd BJTPrep && xcodegen generate && open BJTPrep.xcodeproj`

See `docs/APP_STORE_LISTING.md` for store metadata.
